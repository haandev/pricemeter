`examples/messaging`: Cellonay tarzı bir OTP + WhatsApp servisi. Cloudflare Worker, hesap başına bir Durable Object (ledger, bakiye, sayaçlar), D1 (usage), KV (OTP kayıtları), Queue (geç yayımlanan fiyatlar) ve aylık cron. Prepaid.

```sh
bunx vitest run examples/messaging     # workerd'siz testler (DurableObject shim'i)
cd examples/messaging && bun run dev   # wrangler dev
```

| Dosya | Rolü |
| --- | --- |
| `src/catalog.ts` | Paylaşılan katalog; adapter yok |
| `src/prices.ts` | Katmanlı fiyat tablosu + rota maliyeti yedeği |
| `src/app.ts` | Worker mantığı: OTP gönder / tekrar / doğrula / süresi dolsun, WhatsApp penceresi, aylık ücret |
| `src/account.ts` | Hesap DO'sunun mantığı (`AccountCore`), `DurableObject` sınıfından bağımsız |
| `src/do.ts`, `src/worker.ts` | Cloudflare'in örneklediği ince sarmalayıcılar |

## Katalog

<Source file="examples/messaging/src/catalog.ts" body />

Havuz (`msg/free_pool`) önce tanımlanır; SMS ve WhatsApp onu 1 ağırlıkla besler, böylece kanaldan bağımsız aylık 1.000 ücretsiz mesaj kotası (B4) tek bir kademeli tarifedir. Katalog adapter'sızdır: Worker `bind` eder, DO yalnızca `price()` için kullanır.
