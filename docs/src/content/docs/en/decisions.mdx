## A few reading notes

- **No silent zero** (A58, A82): a tariff that needs `usedSoFar` returns `usage_required` when the counter is missing; the library never assumes 0.
- **Value objects** (A87, A101): a hold comes back updated from every call and carries one line per `(meter, dims)`.
- **One package** (A105): the SQLite and Cloudflare adapters are the `pricemeter/sqlite` and `pricemeter/cloudflare` subpaths; they have no dependencies.
- **Result = the price of this call** (A99): a repeated call returns the recomputed `charged`; whether anything was written is `commit`'s knowledge.
- **Counter scope belongs to the app** (A100): the reference adapters count per meter; tiers per dimension value are a `getRate` choice.
